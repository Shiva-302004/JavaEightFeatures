# Day 2 Assignment – Address Book & User Registration (Java OOP)

## 📌 Overview
This project is the outcome of **Day 2 Assignment**, aimed at strengthening the understanding and practical implementation of **Object-Oriented Programming (OOP) concepts in Java**.

The assignment focuses on building a **simple Address Book application** along with **User Registration and Validation logic**, demonstrating how multiple classes work together to form a structured and modular Java application.

---

## 🧩 Project Structure


---

## 📂 File Description

- **Person.java**  
  Represents an individual with personal details such as name and contact information.  
  This class acts as a data model and demonstrates encapsulation.

- **AddressBook.java**  
  Manages a collection of `Person` objects.  
  It provides functionality to store, access, and manage address book entries in an organized manner.

- **UserValidation.java**  
  Handles **user registration and input validation** logic.  
  This ensures that user data entered into the system follows defined rules and constraints.

- **Main.java**  
  The entry point of the application where objects are created and interactions between AddressBook and UserValidation are executed.

- How to create a **User Registration and Validation module**
- How to separate concerns by assigning responsibilities to different classes
- How to write clean, modular, and maintainable Java code

# Day 3 Assignment – Java 8 Features & Date-Time API

## 📌 Overview
This project represents the outcome of **Day 3 Assignment**, focused on exploring and implementing **advanced Java 8 features**.  
The assignment is divided into three main modules that demonstrate **method references, functional programming, stream operations, and the new Date & Time API** through practical problem statements.

---

## 🧩 Assignment Modules

### 1️⃣ Java 8 Method References
This module covers different types of **method references** in Java 8, including:
- Static method references
- Instance method references (particular and arbitrary objects)
- Constructor references
- Method references with predicates, streams, optionals, and functional interfaces

These problems demonstrate cleaner and more readable code compared to traditional lambda expressions.

---

### 2️⃣ Java 8 New Date & Time API
This module focuses on the modern **java.time** package, including:
- `LocalDate`, `LocalDateTime`, and `Instant`
- `Period` and `Duration` calculations
- `DateTimeFormatter` for custom formatting
- `ZonedDateTime` and time-zone conversion
- Leap year checks and daylight saving time detection
- Real-world problems like birthday countdowns and execution time measurement

---

### 3️⃣ Java 8 Stream & Functional Programming Problems
This module applies **streams and functional programming concepts** to real-world scenarios such as:
- Employee data processing
- Product sales analysis
- Book recommendations
- Insurance claims analysis
- Policy holder risk assessment
- Fraud detection

Operations include filtering, mapping, sorting, grouping, aggregation, pagination, and alert generation using streams.

---

## 🎯 Learning Outcomes

By completing this **Day 3 assignment**, I have learned:

- In-depth usage of **Java 8 Method References**
- Practical application of **Functional Interfaces**
- Writing clean and expressive code using **Streams API**
- Performing complex data processing using:
    - filter
    - map
    - sort
    - groupBy
    - reduce and aggregation
- Effective use of **Java 8 Date & Time API** for real-world date-time problems
- How Java 8 improves code readability, maintainability, and performance
- Applying functional programming concepts to **enterprise-level problem statements**

---

## 🏁 Conclusion

This **Day 3 assignment** significantly strengthened my understanding of **Java 8 features** by combining theoretical concepts with real-world problem-solving.  
Through method references, streams, and the new Date & Time API, I learned how modern Java enables concise, readable, and efficient code.

The assignment provided hands-on experience in functional programming and advanced data processing, forming a strong foundation for building scalable and production-ready Java applications.
